| [1](#verse-1) | சிறப்பீனுஞ் செல்வமு மீனு மறத்தினூஉங் <br> காக்க மெவனோ வுயிர்க்கு |  |

| [4](#verse-4) | மனத்துக்கண் மாசில னாத லனைத்தற <br> னாகுல நீர பிற |  |
| [5](#verse-5) | அழுக்கா றவாவெகுளி யின்னாச்சொன் னான்கு <br> மிழுக்கா வியன்ற தறம் |  |
| [6](#verse-6) | அன்றறிவா மென்னா தறஞ்செய்க மற்றது <br> பொன்றுங்காற் பொன்றாத் துணை |  |
| [7](#verse-7) | அறத்தா றிதுவென வேண்டா சிவிகை <br> பொறுத்தானோ டூர்ந்தா னிடை |  |
| [8](#verse-8) | வீழ்நாள் படாஅமை நன்றாற்றி னஃதொருவன் <br> வாழ்நாள் வழியடைக்குங் கல் |  |
| [9](#verse-9) | அறத்தான் வருவதே யின்பமற் றெல்லாம் <br> புறத்த புகழு மில |  |
| [10](#verse-10) | செயற்பால தோரு மறனே யொருவற் <br> குயற்பால தோரும் பழி |  |
